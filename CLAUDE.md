# Veer's job-application workspace

- `Veer_Pratap_Singh_Complete_Profile.md` is the single source of truth about Veer: facts, numbers, dates and open items. Update it whenever he shares new information.
- To find jobs, use the `job-search` skill (`/job-search`). It searches LinkedIn (through Apify), the Bundesagentur für Arbeit, freehire and Arbeitnow across Germany and ranks the 30 best matches. It writes `jobs/<date>/`: `jobs.json`, an Excel workbook and a job board. `/job-apply <number>`, or a click on the job board, builds the application for one of those jobs.
- The desktop app (`app/job_agent.py`, opened from the "Germany Job Agent" desktop shortcut) checks every source on demand and the free ones every few hours (a Windows scheduled task runs `job_agent.py --check` while it's closed), notifies him about strong new matches, keeps its job list in `jobs/app/`, and builds applications headless with Claude Code or Codex into `applications/<date>_<Company>_<Role>_<engine>/`. It records his skill answers and each finished application set in the profile itself.
- For any job link or job description, use the `job-apply` skill (`/job-apply <link or pasted posting>`). It writes the tailored CV, the cover letter and the interview-prep plan, and compiles and checks the PDFs.
- Before putting any skill that isn't in his profile on a CV, ask Veer whether he has it. If yes, add it to profile section 7 and use it. If no, leave it off the CV and record it in profile section 16 and the prep plan. There is no "Currently learning" line.
- PDFs must contain no links or other active content, because SAP SuccessFactors-style portals reject them. Build with `python .claude/skills/job-apply/scripts/build_cv.py`.
